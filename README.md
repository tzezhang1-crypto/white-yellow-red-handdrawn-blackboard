# 白黃紅手繪黑板風格

這是一個可重複使用的 Codex Skill，用於把繁體中文教學、閱讀理解或說明型簡報套用成深綠黑板底的白、黃、紅手繪線稿風格。

## 使用方式

在 Codex 中直接指定：

```text
$white-yellow-red-handdrawn-blackboard
```

也可以說：「請使用白黃紅手繪黑板風格製作這份簡報。」

## 風格範例

- `examples/ChatGPT_chalkboard_reference.png` 是本 Skill 的主要視覺參考圖。
- 範例圖是人物處理、線稿密度、黑板肌理、文字筆觸、色彩階層與版面留白的視覺基準，不只是配色參考。
- 不得擷取範例圖中的文字作為文章內容；可依來源內容調整頁面構圖，但必須保留範例圖的視覺語彙與製作品質。
- 人物不得簡化成圓頭、火柴人、低細節卡通或扁平圖示；文字不得改用規整幾何黑體、乾淨 UI 字體或細書法字。

## 風格規範

- 畫布預設為 16:9；製作圖片型簡報時使用 1920×1080。
- 背景使用深森林綠或黑板綠，保留範例圖可見但克制的紙張、鉛筆或粉筆肌理；文字中央區域應比邊緣更安定，白色斑點與亮色噪點要少。
- 白色作為主要手繪粉筆線稿；線條需有分層、粗細變化、微小刮痕與不均勻筆觸，不使用過度光滑的向量圖作為主要語言。黃色與紅色只用於少量重點輪廓、箭頭、底線、警示記號與點綴。
- 插畫使用具細節的粉筆線描，人物、物件與場景都要保有範例圖的線稿密度；不得以扁平 UI 圖示、簡化 icon 或低細節符號取代人物與主要插圖。
- 背景插圖占比上限：人物、物件、場景線稿、影片框與流程圖等具象背景插圖，合計不可超過該版面的 1/3；分散在不同位置的插圖仍須合計計算，不得用切割或散置方式規避。全版黑板肌理不列入插圖占比，剩餘版面應優先保留文字安全區與可讀的教學內容。
- 所有文字層級，包括標題、內文、標籤、數字、清單、指標與備註，都要使用與範例圖一致的「粗筆畫、略帶不規則手寫感的白色粉筆字」；字內保留斷續刮擦與細微顆粒紋理，大標筆畫可較厚，但不可做成規整的幾何方塊黑體。
- 真人手寫筆觸：每個字的筆壓、筆畫粗細、轉折、字距、傾斜與基線都要有自然細微差異，像真人以粗粉筆直接書寫；必須保持清楚可讀，不得只用數位字體加濾鏡或隨機扭曲冒充手寫，也不得使用細書法、印刷體或規整幾何字。
- 文字需高畫質、清楚易讀；粉筆質感保留在字內，文字四周不得出現白色點點、粉塵或噪點光暈。
- 文字內容須保持繁體中文與來源核准字串的正確性；數字、標點、斜線與符號不可任意改寫。
- 文字區要保持乾淨，插畫、箭頭、影片框、人物與背景裝飾不得穿過或遮蔽文字。
- 每頁會先排文字安全區，再配置粉筆圖示與流程圖，避免插畫穿字或留下過多空白；版面中的留白必須具有保護文字或強化理解的明確作用。
- 插圖配置應集中於單側或下方角落，且總視覺面積不得超過單頁 1/3；不得為了放大插圖而壓縮標題、內文或文字安全區。
- 最終製作鎖定：所有可見文字都採真人手寫白色粉筆筆觸；每頁先安排文字安全區，再把具象背景插圖群放在單側或下方角落，合計不超過版面 1/3，插圖線條不得穿過、遮蔽或搶過文字。
- 底線必須直接服務於對應標題或文字列，與字保持距離，不得穿字、漂移或碰撞插圖。
- 重複列項的符號、文字基線、卡片與底線需保持一致對齊，並保留適當留白。
- 頁碼若有需要，放在右下角，以白色或黃色手寫風格呈現。

## 人物規範

- 人物以範例圖的真人肖像式或半身姿態粉筆線稿呈現，保留可辨識的頭髮、臉部輪廓、眼神、服裝、姿態與手勢；頭髮、衣服與物件可使用選擇性的排線與刮痕。
- 若版面安排人物，人物應與文字區分離，避免人物線條穿過或遮蔽標題與內文。
- 臉、耳朵、頸部、雙手與露出手臂的皮膚區域，必須與黑板同色透底，不使用白色或灰色填色。
- 皮膚內部只保留極簡的眉眼、鼻口、臉部輪廓、手指與關節修飾線，不使用密集排線或寫實陰影；密集排線應保留給頭髮、衣服、道具與非皮膚區域。
- 除非使用者明確要求，人物下方不加裝飾性水平底線。

## 插圖占比檢查

- 交付前逐頁估算具象背景插圖的合計面積，確認不超過該頁 1/3；黑板紋理、粉筆顆粒與文字刮痕不列入計算。
- 若插圖分成多個人物、物件、影片框或流程圖，必須把各區塊合計後再判定，不得以分散配置規避上限。
- 若插圖超過 1/3，先縮小或移除次要插圖，再調整文字區；不得縮小文字來遷就插圖。

## 常用版型

- 封面與封底：深綠黑板肌理為主，手繪插圖群控制在版面 1/3 以內，保留明確且占主要面積的標題安全區。
- 故事地圖：中央主圖搭配四向概念節點與手繪連線。
- 教學頁：左側文字、右側插畫；需要流程或比較時再使用分格構圖。
- 摘要頁：使用兩張清楚卡片，或以橋梁、關係圖呈現概念。
- 學習單與試卷：保留外框與足夠書寫空間；每題文字框內預設不畫橫線，除非使用者明確要求書寫線。
- 解答頁：文字緊湊但可讀，插畫放在不干擾答案的位置。

## 使用邊界

這個 Skill 只負責視覺風格，不包含特定文章、題目、頁數或固定輸出格式。內容整理、頁面規劃、考題設計、PPTX／PDF 輸出與品質檢查，應依使用者當次需求搭配適合的文件或簡報工作流程。

不得自動混入 JDN 編輯教育敘事風、Academic Clean 學術清爽風、日系繪本風、其他模板、品牌標誌、浮水印、隨機文字或未核准的外部圖片。
