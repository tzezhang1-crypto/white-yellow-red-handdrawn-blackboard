# 白黃紅手繪黑板風格

這是一個可重複使用的 Codex Skill，用於把繁體中文教學、閱讀理解或說明型簡報套用成深綠黑板底的白、黃、紅手繪線稿風格。

## 使用方式

在 Codex 中直接指定：

```text
$white-yellow-red-handdrawn-blackboard
```

也可以說：「請使用白黃紅手繪黑板風格製作這份簡報。」

## 風格規範

- 畫布預設為 16:9；製作圖片型簡報時使用 1920×1080。
- 背景使用深森林綠或黑板綠，可帶有克雷筆、鉛筆或粉筆的細微顆粒。
- 白色作為主要手繪線稿；黃色與紅色只用於重點輪廓、箭頭、底線、警示記號與少量填色。
- 線條保留手繪的不均勻感，不使用過度光滑的向量圖或寫實攝影。
- 文字使用繁體中文、高對比、清楚易讀；插畫不得遮住文字。
- 頁碼若有需要，放在右下角，以白色或黃色手寫風格呈現。

## 常用版型

- 封面與封底：滿版手繪插畫，保留乾淨的標題安全區。
- 故事地圖：中央主圖搭配四向概念節點與手繪連線。
- 教學頁：左側文字、右側插畫；需要流程或比較時再使用分格構圖。
- 摘要頁：使用兩張清楚卡片，或以橋梁、關係圖呈現概念。
- 學習單與試卷：保留外框與足夠書寫空間；每題文字框內預設不畫橫線，除非使用者明確要求書寫線。
- 解答頁：文字緊湊但可讀，插畫放在不干擾答案的位置。

## 使用邊界

這個 Skill 只負責視覺風格，不包含特定文章、題目、頁數或固定輸出格式。內容整理、頁面規劃、考題設計、PPTX／PDF 輸出與品質檢查，應依使用者當次需求搭配適合的文件或簡報工作流程。

不得自動混入 JDN 編輯教育敘事風、Academic Clean 學術清爽風、日系繪本風、其他模板、品牌標誌、浮水印、隨機文字或未核准的外部圖片。
